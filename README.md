# Hermes Obsidian Sync — public information only

This repository hosts only the public app homepage and privacy notice for a personal Google Drive/rclone integration.

- `index.html`: app purpose, access scope and public/private separation.
- `privacy.html`: data use, storage, retention, revocation and contact information.
- No login form, JavaScript, analytics or external assets.

Do not add a Vault, business documents, server addresses, client credentials, OAuth tokens, private logs or backup archives. The separate `hermes-lab` project remains private. This public site is not a synchronization service or a Google verification approval.
